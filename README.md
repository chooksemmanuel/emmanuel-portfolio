# Emmanuel Ihejiamaizu Portfolio

A Next.js portfolio built for Vercel deployment.

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy to Vercel

1. Create a new GitHub repository, e.g. `emmanuel-portfolio`.
2. Upload/push this project to the repository.
3. Sign in to Vercel with GitHub.
4. Select **Add New → Project** and import the repository.
5. Vercel will detect Next.js automatically. Keep the default build settings and deploy.
6. Every push to the production branch (`main`) automatically updates the same production URL.

## Update project content

Edit `app/page.js` for project cards and the files in `app/projects/*/page.js` for case studies. Commit and push. Vercel redeploys automatically.
